!

Independent unsigned beta

StormPad is currently an independent unsigned beta. macOS may block the first launch because the app has not yet been notarized by Apple.

macOS blocked the app?
  1. Try opening StormPad once.
  2. Open System Settings.
  3. Go to Privacy & Security.
  4. Scroll to Security and click Open Anyway.
  5. Confirm by clicking Open.

Only follow these steps when StormPad was downloaded from the official StormPad website or GitHub repository.
