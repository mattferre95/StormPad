# Security policy

## Supported versions

StormPad 0.1.x Beta is currently supported with security updates.

## Reporting a vulnerability

Do not report security vulnerabilities through public GitHub issues.

Use
[GitHub private vulnerability reporting](https://github.com/mattferre95/StormPad/security/advisories/new)
to submit a confidential report.

Include:

- affected StormPad version
- macOS version
- Apple Silicon hardware details when relevant
- clear reproduction steps
- expected and observed behavior
- potential impact
- any known mitigation or workaround

Do not attach real personal notes, private attachments, credentials, or other
sensitive data. Reproduce the issue with sanitized temporary fixtures whenever
possible.

You should receive an acknowledgement after the report is reviewed. Public
disclosure should be coordinated through the private report.
